## 📌 Overview
This task is part of the **AI/ML Track Internship at Code Room Hub**.
The goal was to perform Exploratory Data Analysis (EDA) on an automobile dataset to understand its structure, detect patterns, and identify data quality issues before modeling.

## ✅ Objectives
- [x] Load and inspect the dataset structure

- [x] Analyze feature distributions and relationships
- [x] Visualize key trends and correlations
- [x] Summarize insights from the analysis
